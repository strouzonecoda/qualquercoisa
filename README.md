## 👨‍💻 Sobre mim

Desenvolvedor em São Paulo e estudante de **Análise e Desenvolvimento de Sistemas**. Hoje mantenho e evoluo um **sistema de gestão de ordens de serviço em produção** e desenvolvo **automações com bots (WhatsApp/Telegram)** para pequenos negócios.

Busco uma **oportunidade de estágio em Desenvolvimento de Software** onde eu possa aplicar essa experiência prática e crescer dentro de uma equipe.

- 🔭 Trabalhando em: sistema de OS em produção + automações
- 🌱 Estudando: React, TypeScript, Angular, Java e MySQL
- 💡 Interesses: desenvolvimento web, automação e UX/UI
- 🎮 Fora do código: jogos, música e testar tecnologia nova
